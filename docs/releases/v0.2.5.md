## 変更内容

再現性の良かったKohakuの実機設定を、新規プロジェクトの初期値にしました。

| 項目 | Kohakuの初期値 |
| --- | --- |
| 学習方式 / 学習対象 | LoRA / attn-mlp（Attention＋FFN） |
| Rank / Alpha | 16 / 16 |
| Optimizer / 学習率 | AdamW / 0.0001 |
| Weight decay | 0.00005 |
| Scheduler / Warmup / 学習率下限 | cosine / 0 / 10% |
| 解像度 / Batch / 勾配累積 | 1024 / 1 / 1 |
| 上限 / 保存間隔 | 4000STEP / 100STEP |
| Caption dropout / EMA | 0 / 0（無効） |
| 除外・包含パターン | 空欄 |
| 再開用state | 最新の1つだけ保持 |
| Timestep / 学習用flow shift | sigma / 1.0 |

**速度重視なら学習解像度を512または768へ下げてください。**

RTX 4070 12GBで、この設定の4000STEP学習が2026-10-28に正常終了したことを確認しています。sd-scriptsの初期値と、保存済みプロジェクト・再開stateの設定は維持します。

## 更新方法

アプリを終了し、ZIP内のアプリ本体を置き換えてください。`data/`・`backend/`・モデル・データセットは保持してください。起動ファイルは **Start MOSS LoRA Trainer.bat** です。

## English summary

Kohaku defaults now match the successful RTX 4070 12GB run: LoRA 16/16, attn-mlp, AdamW, LR 1e-4, weight decay 5e-5, cosine with no warmup, 1024px, 4000 steps and saves every 100 steps. Caption dropout and EMA are off, no blocks are excluded, and only the latest resume state is retained. For faster training, lower resolution to 512 or 768. Existing projects and sd-scripts defaults are preserved.
